Halo! Saya seorang web developer dengan pengalaman membangun berbagai jenis website menggunakan `Laravel` dan `Vue.js`.

## Pengalaman Kerja

Saya memulai karier profesional pada awal 2022 sebagai [**Front-End Web Developer**](https://www.w3schools.com/whatis/whatis_frontenddev.asp) di CV Karya Inovasi Anak Bangsa, Banjarnegara. Di sana, saya terlibat dalam pengembangan website dashboard dan integrasi API untuk data keuangan.

Kemudian, saya bergabung dengan PT Prioritas Web Teknologi di Yogyakarta sebagai [**Front-End Web Developer**](https://www.w3schools.com/whatis/whatis_frontenddev.asp), mengerjakan proyek seperti portal berita instansi, sistem audit kearsipan, dan sistem ERP.

Sejak Juli 2023, saya dipercaya sebagai [**Fullstack Developer**](https://www.w3schools.com/whatis/whatis_fullstack.asp). Dalam posisi ini, saya masih mengembangkan frontend dan aktif membangun API, serta berkontribusi dalam memperbaiki performa dan efisiensi sistem.

Saat ini, saya masih bekerja di PT Prioritas Web Teknologi, dan terus mengembangkan kemampuan di bidang web development, khususnya pada sisi backend.
